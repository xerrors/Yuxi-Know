# GUI 操作反馈与文案修补

状态：implemented
类型：bug-fix
Owner：frontend/src/modules/session/ui/GlobalSearchModal.vue

## 问题

搜索切换会清空关键词，路由拒绝、上传失败和资源启用缺少明确的下一步，用户表单没有完整说明用户名规则和登录 ID 的生成时机。GUI 报告包含后端能力和明确不修复的事项，修复标记需要保留每条的实际验证边界。

## 决策

### 实现方案

GlobalSearchModal 保留切换前的关键词，使目标模式重新查询，并取消旧计时器、使旧响应失效。文件空态由查询的调用方传入范围说明：全局及个人空间入口搜索个人空间；会话文件面板按当前目录范围说明对话或关联项目的工作目录。路由守卫沿用原有权限判定和跳转，增加拒绝提示；App 在初始路由未就绪时显示骨架。WorkspaceView 在现有 toast 外保留文件名、失败信息和恢复提示，失败上传继续由后端拒绝。

UserManagementComponent 在 UID 预览和提交前提示现有后端字符规则，并忽略已经过时的预览成功或失败；编辑用户名保留现有登录 ID。表单默认解释 UID 自动生成，列表将 human 的 UID 明确标为登录 ID，APP 终端用户标为终端用户 ID。apis/base.js 仅将公开密码登录端点的 403 映射为账号已注销；该端点的现有拒绝原因由密码登录 service 和 HTTP adapter 拥有，其他错误保持既有脱敏契约。

MCP 页区分新增和启用，说明智能体绑定与 Skill 依赖激活。404 提供返回首页入口，Skill 安装汇总增加冒号，API Key 两个输入框使用数值 maxlength。智能体计数、项目目录、图谱空态使用用户可理解的用途说明。评估列表显示失败基准现有 build_metadata 中的原因，并保留已有继续生成入口。ContextUsagePanel 将累计项标为已上报模型调用的累计用量，只在有正数时显示。

所有修改位于前端及本决策。后端搜索、自动标题、协作深度、知识库统计及评估恢复接口保持原有 Owner 与实现。复合报告建议按实际完成子项标记；原始测试统计保留为测试历史。

## 替代方案

统一透传后端字符串错误会扩大信息暴露面，因此采用表单局部规则提示和登录端点的确定性映射。前端自行累计知识库统计会偏离分页及服务端事实，因此保留现有读取链。扩展检索、自动标题或协作能力需要独立需求和相应后端证据。

## 后果

用户可以保留关键词切换搜索，看到上传失败的文件及恢复方式，理解服务启用、登录 ID 和项目目录的用途。前端格式检查改善交互，后端继续拥有授权与数据约束。零用量隐藏避免把未采集数据表示为有效累计值；用量采集本身由现有后端遥测负责。
