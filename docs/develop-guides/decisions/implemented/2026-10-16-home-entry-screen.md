# 首页单屏输入入口与知识流线

状态：implemented
类型：feature
Owner：frontend/src/pages/HomeView.vue

## 问题

应用首页承担进入工作区的入口职责。用户明确要求只保留一个首屏，通过排版和轻量背景改善质感；产品能力、截图与场景介绍由开源文档首页承担。

## 决策

### 实现方案

HomeView 保持品牌导航、配置口号、居中多行输入和版权页脚；文档入口只在顶栏展示，无外链装饰图标。模板口号为“让知识，成为行动。”，沿用 `branding.title` 自定义入口，以中性色与两级排版展示；输入框使用单层圆角边框与轻阴影，提示为“想问点什么？”。常见 768px 及以上视口中，主要内容和页脚在一个屏幕内展示；矮屏或长配置文案允许自然增高，保证操作可访问。健康检查、错误重试与品牌读取沿用现有契约，产品名称、Logo、口号和登录背景的字段与消费者由[产品品牌配置](2026-10-16-product-branding-config.md)拥有。

KnowledgeFlow 以原生 Canvas 绘制连续曲线、连接与节点，浅深色共用几何和运动，仅替换主题 token。少量节点沿曲线缓慢移动并带细尾迹与呼吸环，输入聚焦或已有文字时背景收淡，中央遮罩保留标题和输入区的留白。HomeAgentPreview 每五秒轮播七个示例智能体的头像与名称，仅作展示，输入聚焦或已有文字时暂停。背景与轮播尊重减少动效偏好，页面隐藏、失活或卸载后停止；Canvas 像素密度上限为 2，绘制上限约 30fps。

输入区右侧固定显示 DeepSeek V4.1 Flash 与向下箭头，不提供模型选择；圆形上箭头发送按钮始终可用。空输入直接进入对话，有文字时交给会话域的单次草稿交接，在新建会话输入框追加并等待用户发送。`thread_draft` 按标签页使用 sessionStorage 暂存文本，覆盖登录与 SSO 整页跳转，不把正文放入 URL、不覆盖已有草稿；SessionWorkspace 仅在激活的新建主会话接收一次。中文候选词确认和 Shift+Enter 保留输入，普通 Enter 与发送按钮执行相同交接。首页不直接调用智能体执行接口。

右上角统一显示“去对话”，沿用登录守卫进入工作区。该入口和发送按钮使用浅色黑底白字、深色白底黑字，悬停与按下保持中性色。主题按钮复用全局 theme store，按浅色、深色、自动循环，自动模式跟随系统偏好并保存选择。

首页只承担应用入口，不包含副标题、产品段落、滚动触发动效、截图资源、暂停按钮、附件上传、真实智能体或模型选择，也不引入 GSAP 依赖。产品介绍继续由文档首页承担，权限与智能体执行保持现有协议。

## 替代方案

- 多段产品介绍页：超出应用入口职责，与用户指定的内容边界冲突。
- 使用概念背景图片或让两种主题分别展示流线与星场：无法满足代码绘制及同一构图要求。
- 仅用静态居中标题：缺少可直接输入问题和任务的入口。
- 输入后直接执行：首页没有真实智能体与模型选择上下文，执行由会话页显式发送。
- 把入口文本直接写入持久会话草稿：可能覆盖保活编辑器的已有输入，采用单次追加交接。
- 引入字体服务和动效框架：单屏入口及独立视觉可用现有样式和浏览器 Canvas 完成，无当前消费者需要这些依赖。

## 后果

背景存在局部 Canvas 绘制开销，以帧率和像素密度上限控制；不引入动画依赖。长标题与较矮视口优先保留内容可读性，不强制裁切成一个屏幕。

输入在工作区等待显式发送，已有草稿保留。sessionStorage 不可用时同页内存仍可交接，整页跳转可能丢失未持久化文本。浏览器 fixture 证明页面交接与可见结果，不证明真实后端认证或智能体运行。

上述浏览器验收、交接与品牌相关 unit、前端 lint 和 build 已通过。品牌模板口号 oracle 显式更新，对应后端系统路由 unit 的 4 项已通过。浏览器负控通过临时响应变体验证，工作区源码不为负控改写；fixture 不替代真实登录、SSO 或智能体执行证据。

旧能力不存在：产品介绍段落、副标题、场景轮播、滚动触发器、专用截图与 GSAP 依赖从应用首页移除，浏览器资源断言拒绝介绍页专用资源。

重新引入条件：有明确需求要求应用首页承载产品说明或直接执行任务时，重新裁决内容与执行边界。
