# 演示搜索失败与产物预览更新

状态：implemented
类型：bug-fix
Owner：frontend/src/modules/session/ui/workspace/AgentPanel.vue

## 问题

搜索配额失败必须在工具协议、历史读取和页面中显示失败原因，不能显示为正常零结果。当前搜索服务已将供应商失败转换为领域异常，注册工具将其转换为错误 ToolMessage；历史搜索结果仍存在仅含 `error`、外层标记完成的持久内容，页面状态与错误正文需要一致。

从交付卡片打开的产物只有 runtime 路径，没有文件树元数据，不能进入现有 Workdir 元数据轮询。轮次完成时预览刷新也受文件树范围限制，导致实际文件已经更新而当前页面仍显示旧内容。重复点击同名交付卡片必须能读取当前文件。

## 决策

### 实现方案

保留当前搜索服务、工具异常与归一化契约，为注册工具到公开结果增加额度失败和真实零结果的回归覆盖。前端工具状态投影仅为已有网页搜索结果识别非空顶层 `error`，使历史搜索卡片、汇总与错误正文一致，不修改历史数据库记录，不把其它业务工具任意字段当执行失败。

SessionWorkspace 在当前线程终态通知时递增预览刷新版本，不受页面前后台影响；AgentPanel 释放当前线程缓存。可见活动文件重新读取，隐藏面板和其它标签中的文件在重开时读取。显式重复打开缺少元数据的产物也重新读取。现有 Workdir 元数据轮询继续负责运行期刷新；迟到请求不能覆盖新缓存。reactive Map 中共享请求按 toRaw 后的文件对象确认归属，避免等待方将响应误判为失效而保留加载态。

文件授权、runtime 路径、预览转换与后端缓存边界保持原有 Owner；前端按既有终态通知刷新，不提供历史产物快照。

## 替代方案

只修提示词或要求用户关闭标签不能修复页面状态。每秒重新下载和转换所有产物会产生重复流量、PPT 转换与 iframe 重置。新增文件版本协议和历史快照超出本次两个缺陷的范围；现有终态刷新通知足以证明本次验收。

## 验证

注册搜索工具回归覆盖三种供应商配置的额度错误和成功零结果；真实模型探针产生失败公开结果，历史额度错误在页面展示失败图标、汇总与原始原因。组件负控覆盖仅含 error 的历史完成记录、正常零结果和其它工具同名业务字段。

实际 SFC 回归读取内容，覆盖终态同名更新、重复交付卡片、手动刷新、KeepAlive、隐藏面板、协作标签和个人文件切换；恢复旧行为后读到旧预算。其它线程缓存和失效前迟到请求另有回归保护。前端完整 unit 707 项、lint 和 build 通过。

真实模型在原会话更新报告、HTML、JSON 与 PPT，保持旧网页打开并经历 API 重启。完成后同一页面显示 8 万元预算、四周上限、6.8 万元方案，重新点击最新同名卡片仍为新内容；performance.timeOrigin 未改变。新旧文件、原会议纪要与上一版副本逐份比较，网页真实 DOM 与八页 PPT/PDF 独立核验，详见[复跑审计](../../audits/demo-recheck-audit-2026-10-18.md)。

## 后果

轮次终态可能释放当前线程中未修改文件的缓存，下一次打开需重新读取；这是缺少逐文件修改事件时接受的有界代价。真实演示依赖外部模型与搜索额度，供应商阻断与产品失败分别记录。完整复跑只使用虚构资料，不变更其它会话和全局供应商配置。
